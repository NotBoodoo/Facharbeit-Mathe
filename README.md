# Facharbeit-Mathe
Wie kann die Position eines Roboterarms mithilfe mathematischer Modelle berechnet und durch einen realen Roboterarm überprüft werden?

Python-Library (Bibliiothek), die für diesen simulation brauchen werden:

MatPlotLib https://matplotlib.org/

Numpy https://numpy.org/

# Anweisung zur Installition der Bibliotheken:
- Terminal öffnen
- Diese Befehl einschreiben (Numpy wird Automatisch mit MatPlotLib installieren)

```
pip install matplotlib
```
